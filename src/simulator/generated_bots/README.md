# generated_bots

Каталог по умолчанию для фабрики кода (Слой 15, `simulator.code_factory`).

`python -m simulator --code-factory` записывает сюда для каждого бота поколения:

- `bot_NNNN.py` — независимый модуль Python: литеральные константы (гены, отпечаток,
  поля профиля, приспособленность), один подкласс `SynthesizedBot` и функция `build()`;
- `bot_NNNN.sol` — библиотека Solidity с теми же параметрами в виде констант
  (запись параметров без функций и без исполняемой логики);
- `manifest.json` — SHA-256 каждого файла, история поколений;
- `champions/` — лучший бот каждого поколения.

При каждом поколении файлы `bot_NNNN.*` перезаписываются атомарно. Загрузчик принимает
файл только при совпадении дайджеста с манифестом и при прохождении белого списка AST,
поэтому изменённый вручную файл не будет исполнен.

Боты работают только внутри симулятора (пулы в памяти, жадный билдер Слоя 04) и никогда
не подключаются к сети. Содержимое каталога не хранится в git (см. `.gitignore`).
Другой каталог: `--bot-dir DIR` или `$MEV_SIM_BOT_DIR`.
